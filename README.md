# tz-11-turklub-tropa

Локальный сайт турклуба «Тропа» по учебному ТЗ-11/2026.

## Просмотр

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.
Для проверки через HTTP можно выполнить из корня проекта:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:8765/.

## Состав

- `index.html` — история восхождения, информация о клубе, шесть зимних маршрутов и условия участия.
- `privacy.html` — политика конфиденциальности.
- `css/`, `js/`, `img/`, `fonts/` — локальные стили, анимация, графика и шрифты.
- `docs/promts.md` — исходный запрос, уточнения и результат.

Красный рюкзак поднимается по тропе при прокрутке. На вершине появляется флаг.
Ссылка «Выбрать маршрут» намеренно оставлена пустой и ничего не открывает.
При уменьшенном движении используется статичная сцена; без JavaScript текст и ссылки доступны.

Аналитика, cookies, браузерное хранилище, формы, бронирование и внешние интеграции отсутствуют.
Сайт не опубликован. Название, контакты и реквизиты вымышлены и взяты из учебного ТЗ.
Для публикации нужно установить фактический абсолютный URL `og:image` на обеих страницах
и актуализировать сведения об операторе и инфраструктуре в политике.

## Источники

- Содержание: `.github/TZ-11_Turklub_Tropa.pdf` и его текстовая версия.
- Логотип воссоздан по первой странице PDF. Пейзаж и графика нарисованы в SVG.
- Inter и Russo One: официальный репозиторий [Google Fonts](https://github.com/google/fonts), лицензии SIL OFL в `fonts/`.
- Структура политики: [152-ФЗ, статья 18.1](https://www.consultant.ru/document/cons_doc_LAW_61801/eeeebe22bf738fd65bb66b95cc278911ae2525ee/).

## Проверка

Проверено 20.10.2026 в Microsoft Edge / Chromium:

- Ширины 375, 768 и 1280 px: обе страницы, отсутствие горизонтальной прокрутки, точные отступы логотипа и ссылки политики.
- Начало, середина, вершина, обратная прокрутка, перезагрузка посередине, изменение размера окна и остановка у подвала.
- Пустая ссылка на флаге не меняет адрес и положение страницы. На коротких и широких экранах флаг остаётся в пределах окна.
- Режим уменьшенного движения, отключённый JavaScript, прямое открытие через `file://`.
- Ошибок JavaScript, неуспешных загрузок, сторонних запросов, cookies и записей в браузерное хранилище не обнаружено.

Lighthouse 13.5.0, мобильный режим с имитацией ограничений сети и процессора,
локальный HTTP-сервер: **Performance 78, Accessibility 100, SEO 100**.
Показатели зависят от среды запуска; настройки кеширования будущего хостинга в проверку не входят.
